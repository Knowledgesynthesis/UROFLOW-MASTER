# UroFlow Master

A comprehensive educational platform for learning about urinary incontinence, pelvic floor disorders, and lower urinary tract symptoms (LUTS).

## Features

- **8 Interactive Learning Modules**
  - Urinary Incontinence Types
  - LUTS & Voiding Dysfunction
  - Pelvic Floor Disorders
  - Female Reproductive-Urology Interface
  - Male Reproductive-Urology Interface
  - Neurogenic Bladder Disorders
  - Diagnostic Tools (with interactive PVR interpreter)
  - Stepwise Management Framework

- **Assessment Center** - Test your knowledge with 15+ clinical scenarios
- **Medical Glossary** - Quick reference for urologic terminology
- **Dark Mode** - Toggle between light and dark themes
- **Mobile-First Design** - Fully responsive across all devices

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Vite
- React Router DOM

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser to `http://localhost:3000`

### Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist` directory.

This app is for educational and training purposes only. It does not provide medical advice and should not be used for clinical decision-making. All case scenarios use synthetic data.
