# **6. Reasoning Framework**

Universal evaluation logic:
1. Identify symptom category (stress, urge, obstructive, irritative).  
2. Rule out red flags (hematuria, infection signs, retention, neurologic symptoms).  
3. Use simple tools first (UA, PVR, bladder diary).  
4. Narrow differential via pattern recognition.  
5. Apply step-up management:
   - Conservative → pharmacologic → procedural.  
6. Determine when pelvic floor or urology referral is needed.  
7. Reassess symptoms and iterate.  

**Pitfalls to highlight:**
- Confusing urge incontinence with OAB vs IC.  
- Overdiagnosing UTI without UA support.  
- Missing retention → overflow pattern.  
- Misinterpreting PVR values.  
- Overusing antimuscarinics in older adults.
